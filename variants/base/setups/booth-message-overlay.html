CodingBooth Help

You're inside a CodingBooth — an ephemeral, reproducible dev environment running in a container. The floating Booth panel is your control surface for it.

Restart / Shut Down

Restart re-reads your configuration and rebuilds the booth in place. Shut Down stops and removes the container — anything not saved in your mounted project folder is gone after that.

Idle indicator

Shows when idle shutdown is active, and lets you pause or disable it if you'll be away from the keyboard but still want the booth running.

Full screen

Where shown, this puts the booth in full screen and, while it is, takes back browser shortcuts (like Ctrl+W) that would otherwise be swallowed by the browser tab instead of reaching the booth — see the Clipboard tab for the equivalent friction with copy/paste.

More detail lives inside the booth itself, at /opt/codingbooth/GUIDE.md.

This desktop runs remotely, inside your browser — so your computer's clipboard is not automatically shared with it. Regular Ctrl+C / Ctrl+V only work within the desktop, not across that boundary. There's a separate panel for crossing it, and it works differently in each direction:

1. Open the panel

Click the small gray tab with an arrow, flush against the left edge of the desktop. Then click the clipboard icon in the bar that slides out — a panel titled "Clipboard" opens, with a text box.

2. Sending text INTO the booth (reliable)

Paste or type your text into that box. It's sent to the desktop right away — switch to any app inside the booth and press Ctrl+V to paste it there normally.

3. Getting text OUT of the booth (not always reliable)

Copy something inside an app in the desktop, then check that same box — it may appear there automatically. If it doesn't: that's a known limitation of this desktop image, not something you did wrong — the in-desktop clipboard isn't fully bridged to this panel yet. Select and copy again from inside the app if the first attempt didn't register.
