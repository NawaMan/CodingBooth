# Sample notes for AnythingLLM

AnythingLLM is a self-hosted chat UI that turns documents into context for any
LLM. This file is here so you have something to upload on first run.

- CodingBooth copies the official `mintplexlabs/anythingllm` image into the booth.
- The UI listens on port 3001 by default.
- Storage lives in `~/.anythingllm`. Add `+persist` to keep it across booths.
- Ollama in the same booth is `http://127.0.0.1:11434`.
