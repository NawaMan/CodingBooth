# PHP Example

A minimal PHP environment with Composer for dependency management.

**Stack:** PHP, Composer

## Quick start

```bash
# 1. Launch the booth
cd examples/workspaces/php-example
booth

# 2. Inside the booth — run the anagram demo
./run-anagram.sh listen silent
```

## What's included

| Component | Details                              |
|-----------|--------------------------------------|
| Runtime   | PHP CLI                              |
| Package   | Composer                             |
| Sample    | `src/anagram.php`                    |
