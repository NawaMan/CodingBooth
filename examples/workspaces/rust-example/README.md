# Fizzbuzz

A classic FizzBuzz implementation in Rust.

## Features
- Print FizzBuzz for a range of numbers
- Configurable start and end range
- Classic rules: Fizz for 3, Buzz for 5, FizzBuzz for both

## Usage

```bash
cargo run -- 1 15
cargo run -- 1 100
```

## Development

Build:
```bash
cargo build
```

Run:
```bash
cargo run -- [start] [end]
```

Run tests:
```bash
cargo test
```
