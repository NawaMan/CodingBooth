# Empty Example

This example is a near-empty CodingBooth scaffold meant as a starting point for building a workspace from scratch. Its `.booth/Boothfile` installs nothing but a commented `setup` hint, and its `config.toml` enables only shell history, leaving the reproducible base variant untouched. Starting from a minimal, reproducible base means you add exactly the tools you want with a line or two — `setup jdk 25`, `setup nodejs 22` — and carry none of the bloat a kitchen-sink image drags along. Because the base is pinned and reproducible, the workspace you build stays identical for every teammate and every rebuild, so it's the honest starting point for a new project or for learning how a Boothfile is put together. Begin from nothing, declare what you need, and the booth builds precisely that.
