\section{Introduction}
\label{sec:intro}

The prime-counting function $\pi(x)$ gives the number of primes not exceeding $x$.
The prime number theorem, proved independently by \citet{hadamard1896} and
\citet{poussin1896}, states that
\begin{equation}
  \label{eq:pnt}
  \pi(x) \sim \frac{x}{\ln x} \qquad \text{as } x \to \infty.
\end{equation}
Section~\ref{sec:results} compares Equation~\eqref{eq:pnt} with exact counts.
