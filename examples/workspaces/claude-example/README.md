# Claude Code Example

This example is a minimal booth that has [Claude Code](https://docs.claude.com/en/docs/claude-code) preinstalled. Generated by `booth config --select claude-code`, it puts Anthropic's official terminal agent on your PATH, so you just set an API key and run `claude`. Batteries-included: the Claude Code CLI comes preinstalled in an otherwise minimal booth, ready the moment it launches. No Node setup, no `npm install -g`, no version wrangling — drop your API key in and you have Anthropic's terminal agent working in a clean, disposable sandbox. It's the fastest way to give Claude Code a self-contained workspace to operate in, isolated from the rest of your system.

**Stack:** Claude Code CLI

## Quick start

```bash
# 1. Launch the booth
cd examples/workspaces/claude-example
booth

# 2. Inside the booth — start a Claude Code session
claude
```

## What's included

| Component | Details                                              |
|-----------|------------------------------------------------------|
| Tool      | `claude` CLI (Anthropic's official terminal agent)   |

This template is generated by `booth config --select claude-code`. Set your Anthropic API key once inside the booth (or persist it via `~/.config/anthropic/`) and Claude Code is ready to use.
