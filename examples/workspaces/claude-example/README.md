# Claude Code Example

A minimal booth that has [Claude Code](https://docs.claude.com/en/docs/claude-code) preinstalled.

**Stack:** Claude Code CLI

## Quick start

```bash
# 1. Launch the booth
cd examples/workspaces/claude-example
booth

# 2. Inside the booth — start a Claude Code session
claude
```

## What's included

| Component | Details                                              |
|-----------|------------------------------------------------------|
| Tool      | `claude` CLI (Anthropic's official terminal agent)   |

This template is generated by `booth config --select claude-code`. Set your Anthropic API key once inside the booth (or persist it via `~/.config/anthropic/`) and Claude Code is ready to use.
